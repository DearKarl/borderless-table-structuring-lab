The combined V6/V7 release stays intact under V6; V7 links to its preserved model package. Shared whole-page records, the root application, training components, evaluator and licensing notices remain shared resources outside Version. The small `versions` package preserves original Python import names; it is not a second version archive. Local unpublished campaign files keep their existing locations.

Original source, models, result records and hash-bound archives retain their bytes. Some archived documentation embeds original repository paths. Each version's [preserved-link map](V0/NAVIGATION.md) resolves those historical paths; corresponding maps are available in every version directory. Historical runtime bindings require review before a fresh execution. No training, inference, rescoring or model publication is performed by this organization.
