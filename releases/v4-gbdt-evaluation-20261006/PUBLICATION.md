# Public export scope

This directory is the public export of the completed local **GBDT+Tele experimental-001** delivery. The original private delivery archive remains unchanged; its SHA256 is `9b4744551ac9b578e468db13f65bccad95d59b137e1e3cb5c00fc6d1ab5ac084`. This public archive has its own hashes and is not that original archive.

The three model files, scientific selection/feature/recognition/scoring logic, original metrics, and Chinese evaluation report are unchanged. Publication replaces owner identifiers, the deployment lease path, and machine GPU identifiers with explicit non-operational placeholders. Ten source-file copies contain these string-only changes: five shared modules in the GPU and CPU trees. No condition, function, threshold, budget, estimator or metric formula is changed. `provenance/PUBLIC_EXPORT.json` maps original to public file hashes; `provenance/ORIGINAL_SOURCE_LOCKS.json` preserves original hash provenance without the removed values.

Private task records, review/command identifiers, authorization documents, run ledgers, internal evidence, credentials and data/weight payloads are not published. The original local ZIP is deliberately not uploaded because it contains the removed deployment identifiers. Historical CPU check records were omitted; public package locks and integrity checks were regenerated. The reported benchmark belongs to the original bound execution, not to a new benchmark of this public export.

The placeholder owner/GPU/lease identifiers do not authorize or configure a deployment. The public snapshot cannot launch unchanged: an independently reviewed environment binding, external dependencies and genuine run authorization are required. Do not replace these placeholders by bypassing validation or reuse an existing run. No OCR, training, scoring, GPU access or dependency installation was performed during publication.
