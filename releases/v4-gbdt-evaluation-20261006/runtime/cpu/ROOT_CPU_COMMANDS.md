# CPU scoring source archive

This is the public export of the completed single-group CPU scorer. Its package lock has been regenerated for the public files. Historical execution used the original private lock recorded in provenance; do not substitute this lock into an existing execution.

The original workflow requires terminal inference, all positively released/reconciled allocations, exactly 1651 frozen prediction files, and a genuine environment binding. Timeout pages remain empty in the original denominator. Ground truth is read only after predictions are frozen.

Deployment identifiers are placeholders in this public source tree. It cannot launch unchanged. Consult the top-level README and PUBLICATION.md before any separately authorized environment adaptation. The entry module is `hybrid.v4_selected_eval.experimental_evaluate`; `submit` persists one attempt, `status` observes it, and `collect` only collects that attempt without scoring again. Original deadline/reaping/owned-container-release checks remain in source.

The archived original score is complete. No new inference, scoring, dependency install or container operation was performed to publish this source.
