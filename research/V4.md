# V4 learned input selection for document parsing

V4 studies whether inexpensive pre-recognition image features can select a
useful input scale for TeleOCR. A GBDT predicts an input action; the selected
view is then processed by the frozen parser. The study evaluates a learned
selection mechanism rather than training a new recognition model.

## Method

The GBDT was trained on 30 PDF groups with 90 action records. Features include
image dimensions, estimated glyph height and reliability, blur, contrast,
whitespace, density, and estimated processor-grid geometry. The completed
benchmark uses raster inputs and two actions:

- **A:** retain the image produced by the native input-processing path.
- **B:** apply up to 1.5× bicubic scaling at that boundary, subject to the native
  3,500-pixel long-side limit.

The evaluation enables the learned policy with margin 0.0 and fallback B.
Preparation uses input features without recognition; each page enters the native
recognition pipeline at most once. This is a raster input-selection experiment,
not a validation of continuous optimal DPI or vector-PDF adaptive rendering.

## Experiment and findings

On 1,651 OmniDocBench pages, Overall was **97.171890**. There were 1,644 completed
pages and seven timeouts retained as empty predictions. The recorded A/B choices
were 241/1410 pages; these counts include fallback behavior and do not measure
causal selector benefit. Component metrics appear in the [results](RESULTS.md).

The study establishes a completed system evaluation. A same-condition comparison
against strong fixed policies is still needed to measure the selector's effect
on quality and cost. The historical TeleOCR V2 result and the published TeleOCR
leaderboard reference use different settings and are not its paired controls.

## Reproduction

The [frozen source and model](../releases/v4-gbdt-evaluation-20261006/README.md)
and [full evaluation record](../releases/v4-gbdt-evaluation-20261006/results/REPORT.json)
identify the experiment. See the [reproduction guide](REPRODUCIBILITY.md) for
dependencies, policy settings and checks. The stored default configuration has
`learned_enabled=false`; reproducing this measured policy requires the documented
experimental entry that enables the same model in memory.

V5 retains V4 as a control while investigating stronger fixed inputs and the
remaining error mechanisms. See the [research proposal](V5_PROPOSAL.md).
